# KeyERP Core Patches Changelog

This directory holds any **justified** patches against upstream ERPNext or Frappe
source that could not be achieved through the supported extension mechanisms
(hooks, CSS overrides, JS injection, template overrides, fixtures, custom
DocTypes).

The target is for this directory to stay **empty**. Every entry below must record:

- **Date** the patch was introduced
- **Upstream SHA** it was authored against (see `UPSTREAM_PINS.md`)
- **Why** no supported extension mechanism was sufficient
- **Scope** — exactly which upstream file(s) it touches
- **Re-apply / conflict procedure** for the upgrade loop (Phase 7)

## Patches

_None. This directory is intentionally empty._
